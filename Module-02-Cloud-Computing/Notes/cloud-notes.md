# ☁️ Cloud Computing Notes

## What is Cloud Computing?

Cloud Computing means delivering IT resources over the internet instead of owning and maintaining physical servers.

Example:
Instead of buying a computer server, you can rent one from Azure or AWS.

---

## Why Cloud Computing?

Traditional Infrastructure

- Buy hardware
- Maintain servers
- High cost
- Difficult to scale

Cloud Computing

- Pay only for what you use
- Scale resources quickly
- High availability
- Accessible from anywhere

---

## Characteristics

- On-demand Self Service
- Broad Network Access
- Resource Pooling
- Rapid Elasticity
- Measured Service

---

## Service Models

### IaaS

Infrastructure only.

Examples:
- Azure Virtual Machines
- Amazon EC2

Customer manages:
- Operating System
- Applications
- Data

Cloud Provider manages:
- Physical Servers
- Storage
- Networking

---

### PaaS

Platform to develop applications.

Examples:
- Azure App Service
- Azure Functions

Customer manages:
- Application
- Data

Cloud Provider manages:
- Runtime
- Operating System
- Infrastructure

---

### SaaS

Ready-to-use software.

Examples:

- Gmail
- Microsoft 365
- Salesforce

Customer simply uses the application.

---

## Deployment Models

Public Cloud

Owned by cloud providers.

Private Cloud

Owned by one organization.

Hybrid Cloud

Combination of Public and Private Cloud.

---

## Virtualization

Virtualization allows multiple Virtual Machines to run on one physical server.

Benefits

- Better resource utilization
- Lower cost
- Easy management
