# Linux Notes

## pwd

Shows the current working directory.

Example

```bash
pwd
```

---

## ls

Lists files and directories.

```bash
ls
ls -l
ls -la
```

---

## mkdir

Creates a directory.

```bash
mkdir test
```

---

## touch

Creates an empty file.

```bash
touch file.txt
```

---

## mv

Moves or renames files.

```bash
mv old.txt new.txt
```
