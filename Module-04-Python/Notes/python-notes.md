# 🐍 Python Notes

## What is Python?

Python is a high-level, interpreted, and general-purpose programming language created by Guido van Rossum and released in 1991.

It is known for its simple syntax, readability, and powerful libraries, making it one of the most popular programming languages.

---

## Why Python?

Python is widely used because it is:

- Easy to learn
- Easy to read
- Easy to write
- Cross-platform
- Open Source
- Powerful
- Supports multiple programming paradigms

---

## Features of Python

### 1. Simple Syntax

Python syntax is similar to English, making it beginner-friendly.

Example:

```python
print("Hello World")
```

---

### 2. Interpreted Language

Python executes code line by line.

Unlike C or C++, there is no separate compilation step.

---

### 3. High-Level Language

Python hides low-level memory management, allowing developers to focus on solving problems instead of managing hardware.

---

### 4. Object-Oriented

Python supports Object-Oriented Programming (OOP) concepts such as:

- Classes
- Objects
- Inheritance
- Polymorphism

---

### 5. Cross-Platform

Python programs can run on:

- Windows
- Linux
- macOS

without major code changes.

---

### 6. Open Source

Python is free to use, modify, and distribute.

---

### 7. Huge Library Support

Python provides thousands of built-in and third-party libraries.

Examples:

- os
- sys
- math
- random
- datetime
- requests
- pandas

---

- Slower than compiled languages
- Higher memory usage
- Not ideal for mobile application development
