# DevOps Interview Questions

## 1. What is DevOps?

DevOps is a culture that integrates Development and Operations to improve software delivery through collaboration and automation.

---

## 2. What are the benefits of DevOps?

- Faster deployments
- Automation
- Better collaboration
- High-quality software
- Continuous monitoring

---

## 3. What is CI?

Continuous Integration is the practice of frequently merging code into a shared repository where automated builds and tests are executed.

---

## 4. Difference between Continuous Delivery and Continuous Deployment?

Continuous Delivery requires manual approval before production deployment.

Continuous Deployment automatically deploys every successful build to production.

---

## 5. Name some DevOps tools.

- Git
- GitHub
- Jenkins
- Docker
- Kubernetes
- Terraform
- Azure DevOps
- Grafana
- Prometheus

---

## 6. Is DevOps a tool?

No.

DevOps is a culture and methodology.

---

## 7. Explain the DevOps Lifecycle.

Plan → Develop → Build → Test → Release → Deploy → Operate → Monitor

---

## 8. Why is automation important in DevOps?

Automation reduces manual work, minimizes human errors, speeds up deployments, and improves consistency.
