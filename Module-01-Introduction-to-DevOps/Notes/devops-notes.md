# DevOps Notes

## What is DevOps?

DevOps is a culture and set of practices that combines Development (Dev) and Operations (Ops) teams to deliver software faster, more reliably, and with better quality through automation and collaboration.

---

## Goals of DevOps

- Faster software delivery
- Better collaboration
- Continuous feedback
- Automation
- High availability
- Reduced deployment failures

---

## Why DevOps?

Traditional software development had separate Development and Operations teams, leading to communication gaps, slow releases, and manual deployments.

DevOps solves these problems by promoting collaboration and automation.

---

## DevOps Lifecycle

1. Plan
2. Develop
3. Build
4. Test
5. Release
6. Deploy
7. Operate
8. Monitor

This process repeats continuously.

---

## Continuous Integration (CI)

Developers frequently merge their code into a shared repository.

Benefits:
- Early bug detection
- Faster builds
- Better collaboration

Popular CI Tools:
- Jenkins
- GitHub Actions
- Azure DevOps
- GitLab CI

---

## Continuous Delivery (CD)

Every successful build is automatically prepared for deployment.

Production deployment still requires manual approval.

---

## Continuous Deployment

Every successful build is automatically deployed to production without manual approval.
